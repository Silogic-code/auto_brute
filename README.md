## 📌 项目简介

**AutoBrute** 是一款基于 Python 的自动化弱口令爆破工具，专为本地局域网靶场设计。它整合了 **网络扫描 + 端口探测 + 协议爆破 + 字典自动爬取**，可一键完成从发现主机到爆破弱口令的全流程。

相比同类工具，AutoBrute 的亮点：

- ⚡ **多线程并发**：扫描速度提升 **30 倍以上**（原版单线程需 2 分 40 秒，多线程仅 **5 秒**）
- 🕷️ **智能字典爬虫**：首次运行自动从 GitHub SecLists 等源爬取协议专用字典，并本地缓存
- 📊 **结果 CSV 导出**：爆破结果自动保存为 Excel 可读的 CSV 表格
- 🧩 **模块化架构**：新增协议只需在 `protocol_forces.py` 中添加一个函数
若无需爆破 MySQL/Redis/SSH，可跳过对应依赖，程序会报错但不会影响其他协议。
